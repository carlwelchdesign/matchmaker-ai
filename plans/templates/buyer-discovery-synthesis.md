## Qualitative decision gates

Use `Yes` or `No` only. A `Yes` finding requires one or more claim-level
`EVD-` evidence IDs from the evidence ledger. Participant references are not
sufficient. Use `None` only for a `No` finding.

| Gate | Finding | Evidence IDs |
| --- | --- | --- |
| Credible demand depends on prohibited guarantees, surveillance, discriminatory selection, undisclosed sharing, or pay-to-rank | No | None |
| Required privacy, safety, or service burden is incompatible with the bounded pilot | No | None |
| Evidence splits materially by cohort | No | None |
| Buying process is unclear | No | None |
| Participants require a materially different service promise | No | None |

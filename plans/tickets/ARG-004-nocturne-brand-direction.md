# ARG-004 — Approve Nocturne brand and cross-platform design direction

## Status

`In progress`

## Outcome

Approve a distinctive, accessible, and maintainable Argent design direction that can be implemented consistently across public web, staff web, iOS, and Android.

## Scope

- Select and document the Argent visual thesis.
- Define the cross-platform token architecture and governance rules.
- Review representative public, member-mobile, and matchmaker experiences.
- Validate the direction against accessibility, privacy, trust, and operational-density requirements.
- Define the evidence required before design-system implementation begins.

## Non-goals

- Production component implementation.
- Final campaign photography or licensed brand assets.
- Pixel-identical rendering across web, iOS, and Android.
- Final approval of campaign-specific partner branding.

## Dependencies

- `ARG-001` product brief and positioning
- `ARG-003` concept and language testing

## Deliverables

- [x] Reject the earlier ivory/forest concept as insufficiently distinctive.
- [x] Compare three materially different visual directions.
- [x] Select direction `02` as the provisional direction.
- [x] Name and document the selected direction as Nocturne.
- [x] Produce a focused system specimen with public, member, and matchmaker views.
- [x] Define a human-readable cross-platform token architecture.
- [ ] Validate critical color combinations with measured contrast.
- [ ] Validate typography with real content and text scaling.
- [ ] Review representative responsive web, iOS, and Android layouts.
- [ ] Review operational density with a practicing matchmaker.
- [ ] Review campaign co-branding and privacy/consent presentation.
- [ ] Obtain final founder approval.
